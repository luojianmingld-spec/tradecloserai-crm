2什么是授权码（应用专用密码）？

为了保证账号安全，大部分邮箱不允许第三方软件直接使用「邮箱登录密码」收发邮件，而是要求使用专用的「应用专用密码 / 授权码」。

  • 不是你的登录密码：授权码是一串独立生成的字符（通常 16 位），只在第三方应用中使用。
  • 需要先开启「两步验证」：多数邮箱（Gmail、Outlook、iCloud、Yahoo 等）要求先开启两步验证，才能生成应用专用密码。
  • 有些邮箱叫「授权码」：QQ、163 等国内邮箱在开启 IMAP/SMTP 服务时生成，也叫客户端授权码。
  • 生成后要立即复制：很多邮箱的授权码只完整显示一次，建议先存到记事本。
常见误解把「邮箱登录密码」填进授权码栏，几乎必然连接失败。请按下方你所用邮箱的步骤，去服务商页面生成授权码。

各邮箱授权码获取方法

找到你的邮箱服务商，按步骤在其官网完成设置，再把授权码填回系统。每家都附了直达链接。

Gmail 谷歌邮箱

?常见问题

添加邮箱时最常遇到的问题与解决办法。

为什么不能直接填邮箱登录密码？
出于安全考虑，Gmail、Outlook、QQ、163、iCloud、Yahoo 等绝大多数邮箱不允许第三方软件使用登录密码收发邮件。必须去邮箱服务商页面生成「应用专用密码 / 授权码」填入。这是正常的安全机制，不是系统问题。
提示「连接失败 / 认证失败 / 用户名或密码错误」怎么办？
① 确认填的是授权码而非登录密码；② 确认该邮箱已开启 IMAP/SMTP 服务（QQ、163 必须）；③ 确认已开启两步验证并生成应用密码（Gmail、Outlook、iCloud、Yahoo）；④ 重新复制授权码，注意别带空格、别漏字符；⑤ 刚生成授权码后等待 1-2 分钟再试，部分服务商同步有延迟。
提示「IMAP 不可用 / 服务器不支持」怎么办？
一般是该邮箱未开启 IMAP 服务，或选择的邮箱类型与账号不匹配（例如把企业邮箱选成了 QQ）。请按本页对应邮箱说明开启 IMAP/SMTP；若用自定义类型，核对服务器地址和端口（IMAP 常用 993/SSL，SMTP 常用 465/SSL）。
Gmail 里找不到「应用专用密码」选项？
必须先开启「两步验证」，应用专用密码入口才会出现。路径：Google 账号 → 安全性 → 两步验证（开启）→ 再回到安全性 → 应用专用密码。如果企业/学校管理的 Gmail（Google Workspace），需管理员允许「应用专用密码」功能。
授权码只显示一次，我忘了怎么办？
授权码无法找回，需到服务商页面重新生成（生成新授权码后旧的自动失效）。在系统里重新添加或修改账号密码即可，无需删除邮箱账号。
添加成功但收不到 / 发不出邮件？
① 收不到：确认系统处于在线状态、邮箱账号状态为「已连接」，必要时点刷新/重新同步；② 发不出：检查发件 SMTP 配置是否由系统自动填写正确，自定义类型时核对发件端口；③ 部分邮箱对新设备/新 IP 有保护，首次连接后等待几分钟再试。
换了授权码，需要重新配置吗？
需要。授权码变更后，原授权码立即失效，请在系统邮箱设置中修改该账号的密码为新的授权码，再测试连接。无需删除账号重新添加。
