0前置准备

绑定前先确认以下三项，缺任何一项都无法完成绑定。

要准备：企业微信管理员账号 / 企业微信已注册企业 / 服务器公网 IP（可联系平台管理员获取）
  • 企业微信管理员账号：只有管理员能创建自建应用、查看 Secret、配置可信 IP。
  • 企业微信企业：已在企业微信注册的企业（work.weixin.qq.com 登录即可查看）。
  • 服务器公网 IP：部署本系统的服务器出口公网 IP，用于配置企业可信 IP（第 3 步）。若不清楚，联系平台管理员索取。

1登录企业微信管理后台，确认/创建自建应用

企业微信的配置都在「管理后台」完成，不是手机 App 里。

完成标志：管理后台「应用管理 → 自建」中已有本系统的自建应用
  1. 用电脑浏览器打开 https://work.weixin.qq.com，用管理员账号扫码登录。
  2. 进入「应用管理」页签，在「自建」分类下查看是否有本系统对应的应用（通常名为 TradeCloser AI 客服 等）。
  3. 已有该应用 → 直接进入 第 2 步 复制凭证。
  4. 没有该应用 → 点击「创建应用」，填写应用名称、上传 Logo、设置可见范围，点击「创建应用」即可生成。
说明创建自建应用本身免费，无需付费购买企业微信任何增值服务。可见范围建议选择对接沟通相关的成员，只有可见范围内的成员数据才可通过 API 操作。

2获取 CorpID / AgentID / Secret 三项凭证

这三项分别来自企业微信管理后台的两个位置：企业信息 + 自建应用详情。

完成标志：复制好三个值，Secret 建议先粘贴到记事本临时保存
CorpID (企业ID)
路径：「我的企业」→ 企业信息 → 企业ID
整串字符，全局唯一，用于标识你的企业。
如：ww1234567890abcdef
AgentID (应用ID)
路径：「应用管理」→ 自建 → 点开应用详情
页面顶部显示的 AgentId，一串数字。
如：1000002
Secret (应用密钥)
路径：应用详情 → Secret → 点击「查看」
需用管理员手机企业微信确认，确认后下发到企业微信 App。
⚠️ Secret 只完整显示一次，务必立即复制保存。
Secret 获取要点点击「查看」后，需要用管理员账号在手机端企业微信 App 内确认，确认通过后 Secret 才会发送到企业微信 App 上。不要关闭页面，确认后回管理后台复制。若遗忘只能重置，重置后旧配置全部失效。

3配置企业可信 IP（关键，不做会报 60020）

企业微信安全机制要求：自建应用只能从「企业可信 IP」内的服务器调用接口。本系统的服务器公网 IP 必须加入白名单，否则测试连接会报错。

完成标志：应用详情的「企业可信 IP」中已加入部署服务器公网 IP
  1. 回到「应用管理 → 自建 → 点开本系统应用」详情页。
  2. 下拉到「开发者接口」区域，找到「企业可信 IP」，点击「配置」。
  3. 输入部署本系统的服务器公网 IP，多个 IP 用英文分号 ; 分隔。
  4. 点击「确定」，保存成功即完成。
常见错误提示若不配置可信 IP，测试连接会提示：errcode:60020 not allow to access from your ip。看到这个错误直接去应用详情配置可信 IP 即可。
若企业已认证，可能需要先配置可信域名才能配置可信 IP，按后台引导完成校验域名归属即可。

4开通客户联系 API 权限（同步联系人用）

系统同步企微外部联系人，依赖企业微信「客户联系」接口。需要在后台把本系统应用加入可调用接口的应用。

完成标志：客户联系中已把本系统应用加入「可调用接口的应用」
  1. 管理后台左侧「客户联系」（旧称：外部联系人）。
  2. 进入「权限配置」，在「使用范围」中确认对接沟通成员已被配置为可使用客户联系功能（未配置则无法调用接口）。
  3. 在「可调用接口的应用」中，添加本系统自建应用（如 TradeCloser AI 客服）。
说明只做「测试连接/保存配置」不要求此权限；只有需要「🔄 同步企微联系人」时才必须开通。若暂不需要同步联系人，可跳过本步。

5在系统内完成绑定

以上 4 步在企业微信后台完成。现在回到本系统，在工厂/货代 Agent 界面完成绑定。

完成标志：面板顶部显示「已接入企业微信」绿色状态
  1. 登录系统，进入「贸易Agent」，切换到「工厂对接」或「货代对接」。
  2. 点击界面右侧图标栏的 🏢 企业微信图标，打开「企业微信设置」面板。
  3. 在表单中填入三项凭证：
    • CorpID（企业ID） * 必填
    • CorpSecret（Secret） * 必填
    • AgentID（应用ID） 可选，用于发消息场景
  4. 点击「测试连接」，看到「企微连接成功」即说明 CorpID / Secret 正确且可信 IP 已生效。
  5. 点击「保存配置」，面板顶部出现「已接入企业微信」即绑定完成。

6同步企微联系人并验证

绑定成功后，可把企业微信中的外部联系人同步到本系统，作为工厂/货代伙伴。

完成标志：面板显示「已同步联系人 N」且系统伙伴列表出现企微同步的伙伴
  1. 在「已接入企业微信」状态下，点击「🔄 同步企微联系人」。
  2. 系统会拉取企微外部联系人，成功后提示「同步完成：共 N 个外部联系人，新增 X 个，更新 Y 个」。
  3. 在工厂/货代的工作文件中即可看到同步过来的伙伴。
同步不到联系人的排查① 第 4 步「客户联系可调用接口的应用」是否添加了本系统应用；② 成员的「使用范围」是否配置；③ 同步的是「外部联系人」，企业内部同事不会出现在列表中。

✓绑定自检清单

按顺序核对，全部满足即绑定成功。

  • ✓企业微信管理后台「应用管理 → 自建」中有本系统自建应用
  • ✓已复制 CorpID（我的企业 → 企业信息 → 企业ID）
  • ✓已通过管理员确认获取 Secret（应用详情 → Secret → 查看）
  • ✓应用详情「企业可信 IP」已加入部署服务器公网 IP
  • ✓系统内工厂/货代右侧栏 🏢 面板已填入三项凭证
  • ✓「测试连接」显示企微连接成功
  • ✓「保存配置」后面板顶部显示「已接入企业微信」
  • ✓（如需）「同步企微联系人」成功并出现伙伴

?常见问题

绑定过程中最常遇到的问题与解决办法。

测试连接提示 60020 "not allow to access from your ip" 怎么办？
这是最常见的错误，原因是没有把服务器公网 IP 加入企业可信 IP。回到企业微信管理后台 → 应用详情 → 开发者接口 → 企业可信 IP → 配置，填入部署本系统的服务器公网 IP，保存后稍等 1-2 分钟再测试。若企业已认证提示需先配可信域名，按后台引导完成域名归属校验即可。
Secret 在哪里看？为什么我点查看没反应？
Secret 在应用详情页（应用管理 → 自建 → 点开应用）的「开发者接口」区域，点击「查看」后需用管理员手机企业微信确认，确认后才会发送到企业微信 App。Secret 只完整显示一次，务必立即复制保存。
AgentID 是必填吗？
在系统面板中 AgentID 标注为「可选」。CorpID 和 CorpSecret 为必填；AgentID 主要用于消息发送等场景，建议一并填入对应自建应用的 AgentId（应用详情页顶部那串数字）。
同步联系人提示失败 / 同步不到任何人？
常见原因：① 未在「客户联系 → 权限配置 → 可调用接口的应用」中添加本系统应用；② 成员未配置「使用范围」；③ 企业微信里还没有外部联系人（只加内部同事不会同步）。请按第 4 步和第 6 步排查。
CorpID、AgentID、Secret 填错/想改怎么办？
重新打开工厂/货代右侧栏 🏢 企业微信设置面板，直接修改对应字段后再次「测试连接」→「保存配置」即可覆盖。Secret 输入框为空时表示沿用已保存的值，只有需要更换时才重新输入。
工厂/货代为什么没有"客户绑定"功能？
工厂对接与货代对接定位为通过企业微信接管沟通，沟通对象是上下游伙伴（外部联系人），因此不提供客户绑定。需要客户上下文的 Agent（如外贸销冠）才保留客户绑定入口。
